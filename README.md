## Theme

I am planning to recreate Akira's Bucket List from [Zom 100](https://en.wikipedia.org/wiki/Zom_100:_Bucket_List_of_the_Dead) anime - Because this is a ToDo List and that was also kindof a ToDo list too... 

## Features

### Functional Requirements (Asked by TOP) :
- Be able to create ToDo items
- Have "Projects", we can create or delete these, and each project holds ToDos... Users can choose where they want to add them.
- Color coding stuff should be possible.
- Each ToDo should have things like title, description, due date and priority.
- Store everything in local storage.
